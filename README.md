# ironcurtainracing.com

The website of Iron Curtain Racing, served by GitHub Pages.

- `index.html`: the landing page.
- `privacy/index.html` and `privacy/hu/index.html`: the privacy policy in English and Hungarian (`/privacy/`, `/privacy/hu/`), with `privacy/style.css`. Both stores' listings and the game link to them (`PrivacyPolicy` in the game's repository, whose `docs/PRIVACY_POLICY.md` is the text's source: change the two together, and the date on the pages).
- `app-ads.txt`: the authorized ad sellers (IAB). Its source is `tools/app_ads/app-ads.txt` in the game's repository; edit it there and copy it here.
- `CNAME`: the custom domain.
